# 🎮 Tic-Tac-Toe

A simple **Tic-Tac-Toe web game** built from scratch using HTML, CSS, and JavaScript.

This project was built as a practical learning project to understand how JavaScript can be used to create an interactive game, manage game state, handle user input, and connect different parts of a web application.

## ✨ Features

* 👥 **2-Player Mode**

  * Two players can play against each other.

* 🤖 **Computer Opponent**

  * Play against a rule-based computer opponent.
  * The opponent is based on predefined rules rather than machine learning or an AI model.
  * The current implementation has a fixed difficulty and symbol selection.

* 🏆 **Score Tracking**

  * Keeps track of the score during the session.
  * Restarting the game currently resets the score history.

* 🎵 **Background Music**

  * Background music is included in the game.

* 💬 **Comment Button**

  * A comment button is included in the interface.
  * The button is currently non-functional because API/backend integration has not yet been implemented.

## 🎮 How to Play

### Two Player

1. Start the game.
2. Players take turns placing their symbols.
3. Get three symbols in a winning pattern to win.
4. If the board is filled without a winner, the game ends in a draw.

### Against the Computer

Play against the computer's rule-based opponent and try to win before it does.
